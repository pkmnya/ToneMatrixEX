# ToneMatrixEX Agent Rules

- **Post-Modification Testing**: After making any code modifications to this project, you MUST run `npm run build` to verify that there are no TypeScript compilation errors or build failures. Do not skip this step, as strict typing is enforced.
- **Git Commit Policy**: DO NOT automatically commit code using `git commit` after making changes. Wait for the user to manually review and commit the changes themselves.
