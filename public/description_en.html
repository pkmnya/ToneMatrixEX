This project was initially inspired by André Michelle's classic work Tonematrix. Here, you can put aside complex music theory. With simple clicks, you can easily "draw" out some melodies with a unique flavor.

Besides just playing around, I'd like to share a very practical workflow: you can save the melodies you create here as an MP3 file, and then import it into Suno AI as the base audio (i.e., an audio mask/prompt). These simple and clean notes can provide a great framework and direction for Suno. I have been using this method for a long time, and the results are indeed very good.

If you scroll down the page, you can hear a few complete songs generated by me (pkm) using this method. However, when I made those songs, I was using an early, purely hand-written version of this project called TonematrixCS.

The current ToneMatrixEX version is the result of my attempt at Agent-assisted programming. With the help of Gemini, the core foundation of the entire project was built in about 3 minutes. After that, I slowly made tweaks and fixes until it became the smooth, fully usable state it is today.
